# Freelance Web Developer Portfolio

Professional portfolio for a freelance full-stack web developer.

## Positioning

Freelance Full-Stack Web Developer building modern, practical websites and web applications for businesses.

## Design direction

- Editorial and utilitarian
- No Inter, Roboto, or SF Pro
- High-contrast serif headlines with utilitarian sans/monospace body text
- Flat surfaces and crisp 1px borders
- No gradients, glassmorphism, shadows, blobs, or neon effects
- No bento layouts
- Minimal, instant interactions
- Plain-language copy

## Planned sections

1. Introduction
2. Services
3. Capabilities
4. Approach
5. About
6. Contact

The portfolio intentionally does not use a fabricated client list, testimonials, statistics, awards, or exaggerated experience claims.
