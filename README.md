# Freelancer Portfolio

Professional portfolio for Reyner, a freelance full-stack web developer.

## Purpose

This repository is a client-facing freelance portfolio. It is intentionally presented as an independent developer site rather than a fabricated agency.

## Current sections

1. Introduction — clear freelance positioning and project CTA
2. Services — business, clinic, booking, application, dashboard, and AI integration services
3. Capabilities — frontend, backend, data, integrations, and deployment stack
4. Process — understand, plan, build, test, and deploy
5. About — concise developer profile and working principles
6. Contact — direct email and phone actions

There is no generic featured-project grid. The portfolio focuses on services, technical capability, process, and direct client contact.

## Design system

- Editorial, utilitarian, asymmetric layout
- Libre Baskerville for display typography
- DM Mono and Arial/Helvetica for utility and body text
- Warm off-white paper background with near-black text
- Crisp 1px borders and flat surfaces
- No shadows, glassmorphism, gradients, neon, blobs, or bento grids
- No slow scroll animations or staggered reveal effects
- Binary hover states and native browser interactions
- Responsive layout with a native `<details>` mobile menu
- Keyboard-visible focus states
- Reduced-motion support

## Deployment

The site is static and can be deployed directly from this repository. If moved to Next.js later, Vercel is a natural deployment target; Next.js officially supports full-stack applications and Vercel provides first-class Next.js deployment support.

## Honesty standard

The site does not claim fabricated clients, testimonials, awards, revenue, years of experience, or project results. Work status should always be described accurately.
